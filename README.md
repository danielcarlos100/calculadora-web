# Calculadora Web

Calculadora web feita com HTML, CSS e JavaScript, que realiza as quatro operações matemáticas básicas: adição, subtração, multiplicação e divisão.
Esta foi minha primeira interface web desenvolvida. O projeto continuará recebendo melhorias e novas funcionalidades, como potenciação e radiciação.
## Funcionalidades

- Adição.
- Subtração.
- Multiplicação.
- Divisão.
- Limpar os valores da calculadora.
- Tratamento de divisão por zero.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `calculadora.html` — estrutura da página.
- `calculadora.css` — estilização da calculadora.
- `calculadora.js` — lógica e funcionalidades da calculadora.
- `calculadora_terminal.js` — versão da calculadora executada no terminal.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `calculadora.html` no navegador para utilizar a versão web.
